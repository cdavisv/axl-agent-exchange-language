# Adaptive typed/JSON switching diagnostic

Experiment date: 2026-11-17. This is a host-side strategy experiment, not a novel syntax claim or model-generation study.

## Question
Can selecting the smaller typed-row or guarded JSON representation per message beat always using JSON when the receiver must know both grammars? Previous experiments tested static formats and shared-field selection, not this mixed-grammar setup cost.

## Method
Use the 38 existing frozen synthetic cases, 16 turns each, unchanged codec at `f408c9024a108df7e6136798b013ab76a0e545c8`. Current public draft PR head was verified as `8743a6839fe5dcb96731564ed29d8fe8f2312773`; its later decoder/cache changes preserve grammar and wire. This study does not benchmark current decoder CPU speed.

The two adaptive arms choose lowest current wire-token count or lowest current full constructed-context count. Ties prefer guarded JSON. Both receive the common instructions, both complete existing format instructions, an explicit dispatch rule and one schema. Past mixed messages remain in history. Every static wire is actually decoded and compared with type-preserving canonical values, 1,824 checks per tokenizer. Adaptive messages reuse those exact validated wires. Shared-field selection is unchanged across all arms. No private data used.

Controls: static guarded JSON (equal per-message identity and safety contract), static typed rows, and negotiated positional JSON (stronger compact control with different out-of-band identity contract). All retain the same data and history. Corpus was already examined; this is a diagnostic, not a fresh heldout evaluation.

## Gemma results
Tokenizer SHA256 `ab26b2add729e6f645bd869f228f14190a06615538f3be6f7786f33d13d78ad2`. Every static control exactly reproduces the previous independent Gemma study.

| Retained turns | Static guarded JSON | Adaptive mixed grammar | Change |
|---|---:|---:|---:|
| 3 | 221,243 | 233,693 | +5.627% |
| 8 | 1,307,503 | 1,334,801 | +2.088% |
| 16 | 4,933,357 | 4,969,217 | +0.727% |

At 16 turns, adaptive wire tokens fall 0.815% (569,758 vs 574,442), but setup/retained context still loses. Negotiated JSON is smaller still: 4,634,069 retained tokens. Wire-minimizing and current-context-minimizing selectors make equivalent-cost choices here; this is not proof of universal equivalence or global optimality.

## Interpretation and limits
Do not add dynamic format switching as a default based on these results. Local wire wins do not pay for teaching both formats on these workloads. No inference, model correctness, output generation, retries, provider billing, tokenizer-selection CPU, real workflow data or native chat-template cost was measured. Setup wording matters. The strategy is available to any JSON-based host; this is not AXL superiority. A next useful gate is model task-success measurement, not more syntax tuning against the same corpus.

## Reproduce
Use a local Python with `tokenizers`; no downloads are performed:

```
python experimental/axl3/codec_switching/study.py --tokenizer /path/to/tokenizer.json --output build/gemma.json
python experimental/axl3/codec_switching/verify.py build/gemma.json --tokenizer-name gemma
```

`verify.py` independently checks 608 observations, wire minima, aggregates, selection counts and recorded summary equality. The script uses the existing project modules and local tokenizer; it never downloads weights/tokenizers or calls a model. Full per-observation outputs are generated by the command; compact checked summaries are committed here. Study artifacts were initially local and are now published unchanged in meaning, with portable paths.

## Qwen cross-tokenizer check

Cached Qwen2.5-Coder tokenizer SHA256 `c0382117ea329cdf097041132f6d735924b697924d6f6fc3945713e96ce87539`, same unchanged inputs and instructions, another 1,824 exact decode checks. Adaptive retained tokens are 220,688 / 1,262,071 / 4,702,605 at 3/8/16 turns, versus guarded JSON 210,840 / 1,247,529 / 4,710,881. The sixteen-turn saving versus guarded JSON is only 0.176%; static typed rows are better at 4,696,781, and negotiated JSON is better still at 4,410,305. Thus adaptive loses to the best static same-contract format on both tested tokenizers at every reported horizon. All results retained, including the small conditional Qwen win against guarded JSON.

## Publication audit

Published as a negative-result diagnostic, not enabled codec selection. Existing static profiles and default behavior are unchanged. Source experiment used f408c90; core implementation later changed while preserving wire. Reproduction against a12d43c1 is checked separately before publication. No elapsed-time comparison is made.
